# Games — Zombie Survival Run

В репозитории лежит исходный Unity-проект **Zombie Survival Run**.

## Структура Unity

Корень проекта содержит `Assets`, `Packages` и `ProjectSettings`.

## Скачивание

В GitHub выберите нужную ветку и нажмите **Code → Download ZIP** либо клонируйте репозиторий через GitHub Desktop.

## Unity

1. Распакуйте архив и добавьте в Unity Hub папку с `Assets`, `Packages` и `ProjectSettings`.
2. Откройте проект в **Unity 6000.3.28f1** и дождитесь импорта ресурсов.
3. Выберите **Zombie Survival Run 0.8 → 2 • Open Game** и нажмите **Play**. Сцена `Assets/Scenes/ZSR_Main.unity` уже включена в проект. Игровой мир появляется после нажатия **Play**.

Если в старой копии проекта настройка прервалась с ошибкой про `Untitled`, сохраните открытую сцену под отдельным именем через **File → Save As**. Затем запустите **Zombie Survival Run 0.8 → 1 • Prepare Project & Scene** и откройте игру через пункт **2 • Open Game**.

## Кампания и управление

**Кампания** состоит из 1000 уровней в 40 районах. Перелистывайте районы стрелками или кнопками ±100. Кнопка **К фронту** выбирает последний открытый уровень.

**Сигнал для двоих** звучит в забегах. Сцены о Максе и Еве выходят на уровнях 5, 10, 15, затем на 25, 35, 45, 55 и 65, дальше каждые 25 уровней от 65 до 990.

| Действие | Клавиатура | Экран |
| --- | --- | --- |
| Смещение влево или вправо | A / D или ← / → | Горизонтальный жест |
| Короткий рывок вперёд | W или ↑ | Свайп вверх |
| Переход на шаг | S или ↓ | Свайп вниз |
| Аптечка / граната | H / пробел | Кнопки внизу |

Рывок действует 0,90 с, шаг — 1,55 с. У двух действий общая перезарядка 4,2 с. Начинайте свайп в области трассы. Дрон включается кнопкой внизу экрана.

В **Арсенале** осмотрите любое оружие, затем выберите его или купите, когда откроется нужный уровень. В **Предметах** стрелка между значениями показывает изменение после покупки улучшения.

На экране результата и в кампании можно вернуться на пройденный уровень за монетами. Повторная победа даёт фиксированную награду и 65% добычи. Новые ранги снаряжения открываются по мере продвижения. Монеты тратятся только при покупке.
