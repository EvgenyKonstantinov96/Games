# Games — Zombie Survival Run

Этот репозиторий подготовлен для хранения исходников Unity-проекта **Zombie Survival Run**.

> ВАЖНО: Полный Unity-проект v0.8 сюда ещё не загружен. Сейчас это только подготовленный репозиторий.

## Структура Unity

Для публикации проекта требуется добавить папки `Assets`, `Packages` и `ProjectSettings`. Не добавляйте `Library`, `Temp`, `Obj`, `Build`, `Builds` и локальные кэши.

## Скачивание

После загрузки файлов проекта нажмите **Code → Download ZIP** либо клонируйте репозиторий через GitHub Desktop.

## Unity

Рекомендуемая версия редактора для существующего прототипа: **Unity 6000.3.28f1**.
