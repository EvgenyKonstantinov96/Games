# Games — Zombie Survival Run

В репозитории лежит исходный Unity-проект **Zombie Survival Run**.

## Структура Unity

Корень проекта содержит `Assets`, `Packages` и `ProjectSettings`.

## Скачивание

В GitHub выберите нужную ветку и нажмите **Code → Download ZIP** либо клонируйте репозиторий через GitHub Desktop.

## Unity

1. Распакуйте архив и добавьте в Unity Hub папку с `Assets`, `Packages` и `ProjectSettings`.
2. Откройте проект в **Unity 6000.3.28f1** и дождитесь импорта ресурсов.
3. Выберите **Zombie Survival Run 0.8 → 2 • Open Game** и нажмите **Play**. Сцена `Assets/Scenes/ZSR_Main.unity` уже включена в проект. Игровой мир появляется после нажатия **Play**.

Если в старой копии проекта настройка прервалась с ошибкой про `Untitled`, сохраните открытую сцену под отдельным именем через **File → Save As**. Затем запустите **Zombie Survival Run 0.8 → 1 • Prepare Project & Scene** и откройте игру через пункт **2 • Open Game**.
