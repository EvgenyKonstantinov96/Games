# Zombie Survival Run — 100 независимых проверок для Codex

## Статус и предпосылки
- **Данный файл — ПЛАН, а не отчёт о пройденных проверках.**
- Объект: текущий Unity проект Zombie Survival Run v1.0.1 + восстановление Polyfork-моделей.
- Целевой Unity: `6000.3.28f1`, Android Portrait, URP.
- **Блокирующий фактор:** пока в GitHub отсутствуют директории `Assets`, `Packages`, `ProjectSettings`, НЕ отмечать проверки как пройденные.
- Требуются исходные утверждённые иллюстрации (прикрепить `docs/design/approved_concept.png`) и реальные кадры из Unity. Текстовые описания не равны утверждённому изображению.

## Протокол каждой проверки
Каждый тест выполняется с новым тестовым запуском: закрыть/перезагрузить соответствующую сцену, восстановить начальные условия, исключить влияние предыдущего теста; заново прочитать изменяемый код и применимые ресурсы. После исправления повторить этот тест и пересмотреть затрагиваемые соседние проверки. Не объявлять 100 запусков, если лишь 100 раз прочитан файл. Для тестов кадра необходим Unity Editor/скриншот/видео. Для статических тестов указывать файл, строку, выход команды.

Для каждого ID сохранить: **status=PASS|FAIL|BLOCKED**, исходный commit SHA, способ запуска, evidence (log/screenshot/video), обнаруженную проблему, внесённое исправление и SHA после исправления. Отчёты: `docs/audit/RESULTS_100.md` и `docs/audit/ISSUES.md`. Каждый фикс — отдельный коммит/PR с проверками.

## Художественный эталон
- Макс и Ева: цельные тактические 3D-персонажи с нормальной анатомией и оружием в руках; никаких круглых примитивов, поднятых плеч или коляски у Евы.
- Шесть классов зомби + босс: различимые силуэты, атаки, движения и реакции.
- Постапокалиптический городской хайвей: объёмный асфальт, разнообразие архитектуры, дым, огни, оранжево-синий свет; дальний фон медленнее дороги.
- Преграды: крупные бетонные блоки, баррикады, ловушки, горящие автомобили и завалы; ясные зоны столкновений.
- Ворота: **только две красивые стойки и полупрозрачная цветная вуаль**, без светящихся круглых обручей.
- Арсенал: по разному изображению пистолета, винтовки, дробовика и минигана.

## Запрещённые фиктивные результаты
- Не обозначать PASS без evidence.
- Проверка JSON, скобок или наличия файла не равна Unity-компиляции.
- Скелетная анимация, motion capture и PBR-модели не считаются установленными без инспекции ресурсов.
- При отсутствии Unity/Android/GPU отмечать BLOCKED и писать точную причину.
- Не заменять скриншот игрового процесса концепт-артом.
- Не считать скачивание GLB их привязкой к объектам игры.
