# Графика, движение и меню Zombie Survival Run

Изменения игры от `671d8f16a7aa8b4a428be8c47297e4c20dd2f333` до `298be4247724037720f2af0f5cd068893f1437c1`, ветка PR #3 в `main`. [Вывод проверок](RUN_VISUALS_AND_PHYSICS_CHECKS.txt).

## Что изменилось в забеге

- У Макса и Евы шаг продолжается во время перезарядки, лечения, броска и попадания. Бёдра поворачиваются по направлению движения, плечи частично компенсируют поворот при прицеливании. У штатной модели автомата скруглены кромки, обновлены силуэт приклада и цевьё, дульная вспышка привязана к оси ствола.
- Семь видов заражённых входили в поворот боком, а после падения скользили со скоростью 52% от скорости дороги. Теперь у каждого вида свой темп поворота и реакция на удар. В семи FBX переработаны позы падения. После затухания толчка тело остаётся на своём участке асфальта до возврата в пул.
- У токсичного заражённого прежний таймер атаки составлял две секунды. При обычном беге он успевал пересечь зону атаки раньше, чем таймер истекал. Теперь заражённый выбирает полосу при замахе, и через 0,42 с выпускает видимый плевок. Ещё через 0,48 с срабатывает проверка попадания по месту приземления. Смена полосы или темпа помогает уклониться. Пул вмещает шесть видимых плевков одновременно.
- Граната получает упреждение в момент выпуска и дальше летит по дуге. Асфальт, дым и осколки учитывают скорость бега. Башенка дрона поворачивается с ограниченной скоростью и открывает огонь после наведения.
- Ворота определяют горизонтальное положение игрока в момент пересечения вуали. Вуаль расступается у плеча, а таблички различаются пиктограммой и короткой надписью. Латунные жетоны с рельефом притягиваются к персонажу. При подборе стоимость начисляется один раз.
- На мосту колея, разметка, выбоины, мокрые участки и ливневые решётки согласованы по координатам. Разметка запечена в материал, что убрало 112 отдельных объектов на четырёх дорожных секциях. Восстановлена ссылка на штатные данные постобработки URP, добавлено сглаживание FXAA для игровой камеры.

## Меню

С главного экрана можно сменить героя и открыть выбранное оружие. Вся карточка героя или оружия реагирует на нажатие. Иконки различают пять разделов и четыре вида снаряжения. Выбранная вкладка выделена цветом и подчёркиванием. При просмотре карточек сохраняется клавиатурный фокус. Панель героя показывает здоровье и темп стрельбы из выбранного оружия.

[Четыре экрана меню](../design/field-kit-ui-preview.jpg) собраны из игровой разметки и текстур вне Unity. [Участок моста](../design/wet-bridge-blender.jpg), [герои в движении](../design/survivor-actions-blender.gif) и [падение заражённых](../design/infected-fall-blender.gif) отрендерены в Blender с моделями проекта.

```sh
python Tools/QA/check_flight.py --unity-data /path/to/Unity/Editor/Data
python Tools/QA/check_toxic.py --unity-data /path/to/Unity/Editor/Data
python Tools/Art/check_premium_assets.py
python Tools/Art/check_campaign_assets.py
blender -b --python-exit-code 1 -P Tools/Art/check_characters.py -- Assets/Resources/ProductionArt
blender -b --python-exit-code 1 -P Tools/Art/check_hero_layers.py -- Assets/Resources/ProductionArt
```
