## Что реализовано

- **Макс и Ева.** Отдельная объёмная одежда с подгонкой к анатомическим телам, настоящими UV и деталями ткани. У Макса короткий рукав, у Евы укороченные рукава куртки; под ними сохранены руки. Уточнены волосы, короткие ботинки, шнуровка и переход к щиколотке. Хвост Евы имеет две дополнительные кости с ограниченной инерцией и возвратом в покой. Коррекция головы по-прежнему восстанавливает исходную позу перед выборкой анимации.
- **Заражённые.** Walker, Runner, Toxic и Crawler получили собственную подогнанную гражданскую одежду, включая асимметричные оборванные штанины. Armored, Brute и Boss сохраняют отличающиеся силуэты, экипировку и поражения тела. Повторно экспортированы все семь FBX вместе с анимациями. Плевок Toxic выходит из точки рта; прямоугольная отметка на асфальте показывает фактическую ширину и длину попадания, движется вместе с дорогой и исчезает при ударе.
- **Материалы и город.** Общий атлас персонажей увеличен до 2048², добавлена карта металличности/гладкости. Старая часть атласа сохраняет плотность исходных текселей, новые большие области отданы одежде. У восьми городских модулей появились балконы, парапеты, оборудование и трубы на крышах. Столбы и придорожные ящики заменены объединёнными мешами со скосами, UV и нормалями. У эвакуационной главы сине-серый туман и тёплый ключевой свет; уточнены смещение теней и мягкие тени URP. Дорожные коллайдеры и доступная ширина сохранены.
- **Оружие и HUD.** Переделаны геометрия пистолета, помпового дробовика и шестиствольного пулемёта. Сохраняются четыре разные принятые иконки Арсенала. Оси дульных точек согласованы с моделями; блок стволов пулемёта вращается и плавно останавливается. Кнопки предметов получили пиктограммы, короткие подписи и счётчики. У здоровья есть задержанный красный след урона. Прежние граната, дрон, аптечка, звуки, музыка и действия ворот сохранены.
- **Меню и диалог.** Новая исходная иллюстрация Макса и Евы подготовлена отдельно для главного экрана, карточек и аватаров. На главной видны оба персонажа, выбранный герой подписан. В Арсенале крупное изображение оружия размещено выше выбора и характеристик; изображение вписывается с сохранением пропорций. Диалог содержит иллюстрацию, лицо, имя, заголовок и ручное переключение; забег ждёт последней кнопки. Сохраняются округлённые поверхности, жирные подписи, переходы и нижняя навигация.
- **Ресурсы и проверка.** Все девять FBX имеют три уровня детализации на одном скелете и общем материале. Настроены пороги LODGroup. Пул неактивных врагов ограничен 12 на обычный тип и одним боссом; предел активных врагов — 44, плевков — 6. При уничтожении игрового объекта освобождается созданный VolumeProfile. Добавлены редакторские команды сохранения Game View и открытия папки снимков. Модели уже входят в ZIP, отдельные загрузки не нужны.

Кампания на 1000 уровней, первые 15 уровней, история, сохранения, монеты, четыре оружия, улучшения, повторные вылазки и управление темпом не удалены. Их численные и управляемые проверки выполнены повторно; прохождение всей кампании человеком не заявляется.

## Повторение доступных проверок

`UNITY_DATA` ниже — отдельная переменная пути к папке `Editor/Data` установленного Unity. Требуются Python, Pillow, NumPy и Blender 4.3 для проверок ассетов.

```sh
UNITY_DATA=/path/to/Unity/Editor/Data
python -B Tools/QA/check_campaign.py --unity-data "$UNITY_DATA"
python -B Tools/QA/check_review.py --unity-data "$UNITY_DATA"
python -B Tools/QA/check_toxic.py --unity-data "$UNITY_DATA"
python -B Tools/QA/check_flight.py --unity-data "$UNITY_DATA"
python -B Tools/QA/check_secondary_motion.py --unity-data "$UNITY_DATA"
python -B Tools/QA/check_interface.py --unity-data "$UNITY_DATA" --output /tmp/zsr-ui-review
python -B Tools/Art/preview_interface.py /tmp/zsr-ui-review
python -B Tools/Art/check_premium_assets.py
python -B Tools/Art/check_campaign_assets.py
blender -b -t 2 --factory-startup --python-exit-code 1 -P Tools/Art/check_characters.py -- Assets/Resources/ProductionArt
blender -b -t 2 --factory-startup --python-exit-code 1 -P Tools/Art/check_hero_layers.py -- Assets/Resources/ProductionArt
```

Для регенерации моделей нужны исходная папка данных MakeHuman и CC0 system-assets ZIP по ссылкам в [LICENSES_ASSETS.md](../../LICENSES_ASSETS.md):

```sh
blender -b -t 2 --factory-startup --python-exit-code 1 -P Tools/Art/build_characters.py -- Assets/Resources/ProductionArt --makehuman-data /path/to/makehuman/data --skin-pack /path/to/system-assets.zip
python Tools/Art/build_production_menu_art.py
python Tools/Art/build_arsenal.py
python Tools/Art/build_street_dressing.py
```
