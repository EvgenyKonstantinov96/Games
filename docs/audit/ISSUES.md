# Блокеры и найденные проблемы

## B001 — критический: нет исходников Unity

**Доказательство:** на ревизии `d80bef6f09074a554f8eea7098fb2be524052cf1` корневой `Assets` — файл с одним переводом строки, а не директория. Не обнаружены реальные сцены, C#-скрипты, персонажи, префабы или игровые ресурсы.

**Влияние:** невозможно исправить игру, собрать APK, оценить 3D-арт и анимации или подтвердить любой из T001–T100.

**Решение:** импортировать оригинальный проект по инструкции `IMPORT_UNITY_PROJECT_RU.md`, предварительно удалив файл-заглушку `Assets`.

## B002 — отсутствует файл утверждённого художественного эталона

**Доказательство:** `docs/design/approved_concept.png` отсутствует в дереве GitHub. Референс доступен в текущем диалоге, но не в исходниках.

**Решение:** загрузить предоставленный рисунок в `docs/design/approved_concept.png` и добавить рядом реальные кадры текущей версии игры для объективного сравнения.

## B003 — неизвестны доступность и лицензии игровых GLB/FBX

**Доказательство:** `AGENTS.md` и Issue #1 требуют восстановления моделей Polyfork и проверки лицензий, но сами файлы и сведения об импорте в данном репозитории не представлены.

**Решение:** предоставить ссылку/локальные источники моделей, лицензию и воспроизводимый путь импорта; не публиковать материалы с запретом на распространение.

Все три пункта остаются **открытыми**. Устранение этих блокеров ещё не означает прохождения Unity-тестов.
