# Zombie Survival Run — открытые вопросы проверки

В текущей версии исправлены замечания по портретам, диалогам и накоплению поворота шеи. [Протокол проверок](REVIEW_FIXES_RU.md) содержит результаты и ограничения. Визуальную приёмку в Unity и Android необходимо продолжить после запуска редактора с лицензией.

Текущее состояние PR #3. Стартовая сцена и девять FBX входят в проект. Последняя проверка C# с настоящими пакетами и отдельная компиляция HLSL завершились успешно. Для проверки импорта Unity, реального игрового кадра, расхода памяти, проходимости и FPS на Android нужен запуск редактора с действующей лицензией. [Проверки и оставшиеся ограничения](RUN_VISUALS_AND_PHYSICS_RU.md).
