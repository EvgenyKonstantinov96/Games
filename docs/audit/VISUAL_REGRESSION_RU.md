# Проверка кадра после регрессии PR #3

Предыдущая ревизия `1ba69680fbc8cf696f195419b44f2893fc6545ad` была запущена владельцем в Unity Device Simulator. В кадре трасса выбелена, дальний фон плоский, большая геометрия попадает в кадр сбоку. Ранее опубликованный рендер моделей в Blender эти проблемы не обнаружил.

## Что изменилось

- Отдельный объект выравнивания вычисляет оси и масштаб FBX по костям головы, таза и ног. Корневые преобразования импортированной модели сохраняются. Стволы теперь имеют размер относительно героев, а трассировка использует дульную точку уменьшенного меша.
- Текстуры имеют настройки TextureImporter. У трассы есть запасная карта и тёмный базовый материал. Панорама рисуется отдельным URP-проходом без тумана поверх текстуры. Туман по-прежнему применяется к геометрии города. В незаписанной сцене стандартная лампа Unity не дублирует свет самой игры.
- У девяти фигур переделаны лица. У Макса и Евы цельные штанины с весами на костях, подогнанные по позам, и новая линия волос. Сетка основана на ресурсах MakeHuman CC0. [Источники](../../LICENSES_ASSETS.md).
- Проверка `Check Shipped Character Pack` использует завод персонажей из игры. В Unity она проверяет габариты уже скинированного меша, положение дула, а также загрузку материалов трассы и горизонта.

Кадр Blender использует экспортированные ресурсы и параметры игровой камеры. Камера, дальняя композиция и размещение нескольких объектов воспроизведены в Blender. Проверка не подтверждает URP, HUD, прохождение 15 уровней или FPS.

```sh
blender -b -t 3 --python-exit-code 1 --python Tools/Art/check_characters.py -- Assets/Resources/ProductionArt
blender -b -t 3 --python-exit-code 1 --python Tools/Art/preview_run_frame.py -- . /tmp/zsr-portrait.png
```

В Unity проверка ресурсов доступна в меню **Zombie Survival Run 1.0 → Check Shipped Character Pack**.
